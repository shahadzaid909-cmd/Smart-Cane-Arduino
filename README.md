# Smart Cane for the Visually Impaired

An **Arduino Uno–based assistive technology prototype** designed to help people with visual impairments identify nearby obstacles using **distance-sensitive vibration alerts**.

## Project overview

The prototype uses obstacle detection and vibration rather than audible alarms. The project poster also describes **GPS integration** as part of the proposed design. Vibration-based feedback is intended to be useful in noisy or crowded environments and for people who may also have hearing impairments.

## Key features

- Obstacle detection
- Vibration alerts that vary based on obstacle distance
- Arduino Uno–based prototype
- GPS integration described in the project poster
- Non-audio feedback for accessibility
